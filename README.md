# recipe-explorer-184409-184527

This workspace contains the Recipe Explorer frontend built with LightningJS (Blits).

Run the frontend:
- cd recipe_frontend
- npm install
- npm run dev
- npm run preview (serves on port 3000 for CI preview)

Style: Ocean Professional (blue primary #2563EB, amber secondary #F59E0B, rounded cards, subtle shadows, gradient accents).
